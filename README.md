# Calmify Vue Frontend

This is the frontend application for the [Calmify](https://github.com/ZapolyarnyDev/Calmify) app.  

## Technologies
- TypeScript
- Vue.js 3
- TailwindCSS v4
- Axios

## Features
- Responsive UI with TailwindCSS
- TypeScript support
- Connects to backend API
- ESLint configured for code quality
- Vite-powered development and build

## Getting Started
```bash
npm install
npm run dev
```
